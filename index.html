01. ¿QUÉ SON?

Pseudoclases: el estilo de cada momento

Una pseudoclase es una palabra que se escribe después de un selector con dos puntos (:) y le da estilo a un elemento solo cuando está en un estado especial: cuando le pasas el mouse, cuando lo marcas, cuando es el primero de una lista o cuando un campo está mal escrito.

No tienes que agregar clases nuevas en el HTML: el navegador detecta el estado y aplica el estilo solo. Abajo encuentras las 18 más usadas; pasa el mouse o toca cada tarjeta para verla en acción.
